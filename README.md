# Quest Game

A mobile puzzle page generated by Python and hosted on GitHub Pages.

Website (after Pages deployment): https://manwe314.github.io/questGame/

## Generate and publish your puzzle

Run these commands from this folder (`Answer`):

```powershell
python PageGen.py "123456" "Your message after the correct answer"
git add docs/index.html
git commit -m "Update puzzle"
git push origin main
```

Replace the example answer and message with your own. Keep quotes around the
answer to preserve leading zeroes. The default output is `docs/index.html`,
independent of your working directory. Use `-o path/to/page.html` for a different
output. Pages serves the HTML; Python runs locally when you create or update it.

The initial page is a demo: answer `123456`, message explicitly marked as a demo.

## QR code

```powershell
python -m pip install -r requirements.txt
python QRGen.py "https://manwe314.github.io/questGame/"
```

The PNG is saved to `qr/questGame.png`. Use `-o "qr/custom.png"` for another file.
Scan it with a phone camera. Verify the website opens before printing the code.
The QR remains valid when you update the puzzle at the same URL.

## GitHub Pages settings

At https://github.com/Manwe314/questGame/settings/pages select **Deploy from a
branch**, branch **main**, folder **/docs**, and save. GitHub automatically
publishes subsequent changes pushed to that folder.

GitHub Pages from a private personal repository requires GitHub Pro. If your
plan does not support it, upgrade or explicitly choose to make the repository
public before enabling Pages. The shared website is public even when the source
repository is private. Repository visibility is not changed by these scripts.

The numeric answer and message are obfuscated in the HTML for a puzzle, not
securely protected against someone inspecting or brute-forcing the page.
